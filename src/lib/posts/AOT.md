# Ashtyn's Own Timer

![Ashtyn's Own Timer](/src/assets/AOT/sm-shot.png)

A pomodoro timing app for Mac OS.

**Keyboard shortcuts**

- space — pause timer
- n — next timer
- command+k — change current time
- command+, — change default times

**Links**

- [[Apple App Store]](https://apps.apple.com/us/app/ashtyns-own-timer/id6741608687)

**Privacy**

No information about the user is collected or submitted to a server.Information
about timers and usage is not collected.
